# 持久化配置、通道探测与已知副作用

[English](../en/09-PERSISTENT-CONFIGURATION.md) · [文档索引](README.md)

## 范围与证据等级

对象为第一代 Middleton / LENNOX，主要研究基线是官方 17.0.37。本文保留成功观察、失败尝试和未解决问题，避免重复研究。它不是全部参数的写入指南，也没有证明某一类未知写入“不会有影响”。基础 UUID、帧格式和声音控制见 [蓝牙通道](03-BLUETOOTH-AND-WINDOWS.md)，升级上下文见 [安装与恢复](02-UPGRADE-AND-VALIDATION.md)。

必须区分四类结论：代码/协议已确认；实机观察；ADK 或配置定义的参考含义；尚无足够证据。读取成功、写入 ACK、读回一致、重启后保留和实际功能变化是不同层次的证据，不能相互替代。

## 通道与编号空间

| 接口 | 已知用途 | 研究边界 |
|---|---|---|
| Classic Bluetooth / A2DP | 音频播放 | LE 管理连接和媒体元数据不能证明音频已接收、解码或输出 |
| GATT `aa08` / `aa16` | 音量及两段 EQ 的读、写、通知 | 属于正常声音设置；不是直接写 PS；不从一次读回推断全部断电持久化语义 |
| GATT `aa10` / `aa11` | 媒体控制相关元数据的观察 | 元数据可用而音乐无声的情况存在；不能用它验证完整 A2DP 路径 |
| GAIA `0x0710` / `0x0712` | PS 记录读取 / STORE_PS_KEY | 物理 PS key 与配置块编号不同；写入长度编码存在目标相关陷阱 |
| GAIA `0x0189` / `0x0109` | GET / SET_TIMER_CONFIGURATION | timer ID 是独立编号空间，不是同号 PS key |
| GAIA 升级通道、PS `0x0004` | 暂存、恢复和提交状态 | 不是日常个性化设置；仅按安装状态机修改必要字段 |
| FE8F / TA 探测 | 历史探测中遇到权限拒绝、无回执，或目标特征不存在 | 没有证据证明这些探测成功修改持久配置；无响应写返回成功不等于设备接受 |

历史命令范围探测包含设置和切换命令，不能统称为只读扫描。缺少逐条执行结果的探测不用于推断“无副作用”。

## PS 记录：确认了什么，没确认什么

| Key | 证据与结论 | 不能据此声称 |
|---|---|---|
| `0x0004` | 已验证的升级上下文；结构、字段保留和恢复检查已在代码中实现 | 可以任意清零或用作关机设置 |
| `0x009D` | 一次历史误写将原 18 字节记录截为 10 字节；恢复同一设备历史完整值、读回并重启后，蓝牙音乐恢复 | 已确定其为音量、路由、codec 开关，或已确定致因的单个字节 |
| `0x008B` | 审计读值与历史基线均为 `0001`；存在旧写入测试代码，但缺少充分成功记录 | 旧脚本注释“session enable”已获验证，或修改无影响 |
| `0x0026` / `0x00C5` | 审计值与历史基线一致，精确字段消费者未映射 | 从未被间接修改，或可安全写任意值 |
| `1/3/5/6/7` | ADK 枚举参考为 AHI / permanent pairing / broadcast mode / Fast Pair index / accounts | 除已独立确认的记录外，该参考等于 Middleton 生产映射 |

PS9D 曾被早期脚本误当作升级上下文；真正上下文是 PS4。恢复音乐的观察支持“损坏该记录与故障有关”，但恢复同时改变长度及多个字节，不能分离各字段作用，也未通过再次破坏记录复现实验。回刷前没有对应完整音频测试，不能把故障归因于回刷官方固件。

目标的历史 STORE 请求存在长度处理差异。一次恢复使用 key、同机历史 18 字节值及额外 18 字节零填充，随后核对完整读回及重启后读回。这是特定设备、特定路径的修复观察，不是通用 STORE 编码规范；不能复制另一台设备的记录或将该补偿用于未知 key。公开目录不包含原始 PS 值、配对数据或恢复用私有快照。

一次有界复核比较了 PS4、PS26、PS8B、PS9D、PSC5 五条记录，均与历史基线一致。另读取 timer ID 0–31，23 条成功、9 条返回状态 `05`；有效值与历史基线一致。该结果仅覆盖这些记录和时点，不证明全部配置未变化。

## Timer 参考映射与反例

以下含义来自 ADK `gaia_timer_param_t` 参考，不代表每一项都已追踪到 Middleton 生产代码消费者。值是研究快照，不是所有设备的默认值。

| ID | 观察值 | ADK 参考含义与单位 |
|---|---:|---|
| 0 | 0 | 自动关机时间，秒；值为 0 不代表 MCU 的独立关机策略已禁用 |
| 1 | 3 | limbo 超时，秒 |
| 4 | 180 | 配对模式超时，秒；不是已确认的 AUX 休眠时间 |
| 5 | 10 | 静音提醒间隔，秒；不是十分钟关机 |
| 6 | 60 | 可连接状态超时，秒；不是六十分钟关机 |
| 9 | 15 | 加密刷新间隔，分钟 |
| 10 | 120 | inquiry 超时，秒 |
| 14 | 0 | A2DP 断链后重连窗口，秒 |
| 16 | 0 | 保存音量/音源前延迟，秒 |
| 17 | 16 | 有线音频连接后的关机超时，秒 |
| 18 | 0 | PS 碎片整理检查间隔，秒 |
| 19 | 3 | limbo 中关闭功放前等待，秒 |
| 24 / 25 | 10 / 10 | 功放取消静音 / 静音等待，毫秒 |
| 28 / 29 | 1000 / 3000 | BR/EDR / LE authenticated payload timeout；参考标注秒，目标单位未独立验证 |

GET 请求为 `[id:u8]`，观察到的成功响应为 `[00,id,value_hi,value_lo]`；SET 请求为 `[id:u8,value:u16 BE]`。可表达 16 位数不代表所有值均有效。跨 LE 重连保留也不等于断电持久化已证实。

历史 id6 修改及恢复有记录，另有置零 sweep 脚本；脚本存在不能证明每个分支实际成功。现有证据不足以通过这些 timer 实现所需 AUX/十分钟策略，因此正式补丁修改的是已识别的 MCU 逻辑，见 [固件修改](01-FIRMWARE-PATCHES.md)。

## 可检索配置定义目录

[机器可读索引](../data/persistent-config-index.json) 收录 523 条带位置的字段定义及 64 个声明块名称，涉及 44 个数字 BlockId，另含 Relative 数组模板。字段保留名称、类型、组和位置；不附带设备实例值。`physical_ps_key: null` 与 `device_write_verified: false` 明确表示尚未建立物理地址映射或逐字段写入验证。

来源为设备导出的配置定义 XML，SHA-256：`23addd2a31b274545382f04fce6fab1a5d122abda38388303a4bbbf5c205cde7`。索引是结构提取结果，不含原始固件和完整 XML；原始材料未随公开源码分发，因此这个哈希用于标识研究来源，不能单凭公开索引重建或独立验证原始文件。

| 配置类别 | 参考 BlockId | 尚需证明的内容 |
|---|---|---|
| A2DP 音量、codec、重连 | 33 | 固件是否启用所列选项；硬件/解码器是否支持 |
| 音源、前级、五段滤波器 | 133 | 生产消费者、实际 DSP 路由；不能直接等同于官方两段 EQ |
| EQ bypass、bank、增强、compander | 41 | 调音及保护路径的相互作用 |
| 音量行为与曲线 | 1232 / 1198 / Relative | 单位、范围和限幅，不应绕过保护 |
| 连接、配对、multipoint | 1053 / 1080 / 33 | 生产启用路径及连接数限制 |
| A2DP/TWS/Wired 延迟 | 1590 | 稳定性与音频断续；不是升级带宽设置 |
| 提示音、LED、按键 | 1186 / 1085 / 59 / 981 / 988 / 196 / 164 | 事件映射、关键提示和按键路径 |
| 模拟输入与有线关机 | 102 / 1349 / 1359 | 与 MCU AUX 功放休眠的区别 |
| 系统休眠、PS 管理、升级 | 1053 / 1499 / 1504 | 不能替代 MCU 600/3600 计数逻辑 |

BlockId、timer ID、GATT UUID、DSP 枚举和 PS key 互不等价。尤其 XML 的 `0x009D` CELT capability 枚举不能解释 PS9D。通用平台定义含 HFP、SPDIF、USB 等条目也不证明该音箱实现这些功能。QCC PS 不能代表 MCU 自身全部存储。

## 复用研究结果的验证方法

新增设置前，应依次建立配置定义→真实存储→生产代码消费者→实际行为的证据链，记录单位、合法范围、基线来源、RAM/非易失性位置、生效时机、重启/断电保持和 App/实体按键覆盖规则。只更改一个已知字段、保留同机完整备份、核对请求及响应长度，并检查无关字段与音频功能。正常业务接口优先于通用 PS 写入。

尚未解决：PS9D 各 word 的精确语义、全部物理 PS 与配置块映射、MCU 独立存储目录及部分历史探测的执行证据。“尚未观察到副作用”不能升级为“写入安全”。
