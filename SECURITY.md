# Security reporting / 安全问题报告

## English

Silver Moon supports the documented Middleton configuration. It does not claim universal Marshall compatibility or absence of vulnerabilities.

Use the repository's [private vulnerability reporting form](https://github.com/RougeNuage/silver-moon/security/advisories/new) for potentially exploitable issues. Include the affected version, minimal reproduction, prerequisites, impact and suggested remediation. Test only devices you own or are authorized to test. Distinguish firmware functionality problems from desktop file-validation, protocol-handling and permission issues.

Do not publish credentials, personal diagnostic data or unredacted device identifiers in public issues. See the [code review guide](docs/en/06-CODE-REVIEWER-GUIDE.md) for review boundaries. A dependency check with no findings is not a comprehensive security guarantee.

## 中文

Silver Moon 仅支持文档明确的 Middleton 配置，不宣称适用于全部 Marshall 设备或不存在漏洞。

对于可能被利用的安全问题，请使用仓库的[私密漏洞报告入口](https://github.com/RougeNuage/silver-moon/security/advisories/new)。报告应包含受影响版本、最小复现、必要前提、影响及建议修复方向。请仅在自己拥有或获授权的设备上测试，并区分固件功能问题与桌面端的文件校验、协议处理、权限问题。

不要在公开 issue 中发布凭据、个人诊断数据或未脱敏的设备标识。审阅边界见[代码审阅指南](docs/zh-CN/06-CODE-REVIEWER-GUIDE.md)。依赖检查未发现问题，不等于全面安全保证。
